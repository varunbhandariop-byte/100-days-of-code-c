# 100 Days of Code in C

## 📌 About the Project

This repository contains my solutions and practice programs from the **100 Days of Code in C** challenge. The purpose of this project is to develop strong programming fundamentals through consistent daily practice.

The programs are organized day-wise to make the learning progress easy to follow and review.

---

## 🎯 Objective

The main objectives of this project are:

* To build a strong foundation in **C programming**
* To improve logical and problem-solving skills
* To understand fundamental programming concepts
* To practice writing clean and structured C programs
* To develop consistency through daily coding
* To maintain and document my programming progress using GitHub

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the required day's folder.

3. Compile the C program using a C compiler.

4. Run the compiled program.

Example:

```bash
gcc Day1.c -o Day1
./Day1
```
